# Считайка

Тренажёр математики для 1–4 классов: 189 тем, подсказки, пошаговые решения и прогресс в браузере.

Темы следуют школьной программе М.И. Моро и соавторов. PDF, сканы и файлы учебников в репозитории не размещаются. Задания создаются тренажёром.

Сайт работает на GitHub Pages без входа в ChatGPT. Необязательная синхронизация прогресса использует внешний сервис; основные занятия работают самостоятельно.
